======================================================
TIME DIVISION (.time-division)
======================================================
32 per staff-unit. IMMUTABLE. Fixed always.
dataset:
  data-time-index         position 0-31
  data-duration-underline "single" | "double" | absent
  data-duration-dot       "true" | absent
  data-rest               "true" | absent
  data-sukui              "true" | absent
  data-hajiki             "true" | absent
  data-keshi              "true" | absent
  data-uchi               "true" | absent
  data-maebachi           "true" | absent
  data-ha                 "true" | absent
  data-tech-arc           "suri" | "oshibachi" | absent  (resolved arc)
  data-tech-arc-armed     "suri" | "oshibachi" | absent  (pending arc, no target yet)
  data-tech-arc-string    string number | absent
  data-tech-arc-offset    division offset to target | absent
  data-triplet            "1" | "2" | "3" | absent
  data-dynamic            "cresc" | "decresc" | absent   (hairpin start division only)
  data-dynamic-length     number of divisions, >= 2 | absent
  data-text-box           text of the box ("" when empty)   (text box start division only)
  data-text-box-length    number of divisions, >= 2 | absent (marks that a box exists)

Note: data-tech-arc and data-tech-arc-armed are mutually exclusive.
      data-tech-arc-armed draws a placeholder arc to the next division
      on the same string (suri) or next string (oshibachi).

Zones (top to bottom):
  .above-zone     height 4mm  — finger-mark OR ha-mark (mutually exclusive)
  .tsubo-zone     3x string-slots
  .clearance-row  height 4mm  — overflow space for technique marks
  .below-zone     height 4mm  — maebachi text

-- String Slot (.string-slot) --
dataset:
  data-string     "3" | "2" | "1" (top to bottom)
classes:
  has-tsubo       slot contains a fret value
  has-rest        slot contains a rest (string 2 only)
  single          duration underline single
  double          duration underline double
  dotted          duration dot

String slot states:
  ""              unplayed string (empty)
  "0"-"19", "#", "♭"  fret value (0 = open string)
  "●"             rest (has-rest class, string 2 only)

-- Above Zone content --
  .finger-mark span    "Ⅰ" | "Ⅱ" | "Ⅲ"
  .ha-mark span        "ハ!"
  (mutually exclusive)

-- Clearance Row --
  .sukui-mark span     "ス"
  .hajiki-mark span    "ハ"
  .keshi-mark span     "ケ"
  .uchi-mark span      "ウ"
  (mutually exclusive — selecting one clears the others)
  (anchored to bottom-most active string slot)

-- Below Zone --
  "マ" text (maebachi) | empty   (same mark in EN and JA; data-maebachi unchanged)
  7pt, line-height 1, top-aligned: マ ink occupies y 20.26–21.97mm (zone is 20–24mm)
  Hairpins are drawn in the lower part of the zone (see Arc Layer)

-- Arc Layer --
  Oshibachi and suri drawn as SVG paths
  Resolved arcs: anchored from start slot to target slot
  Armed arcs: placeholder drawn from start string slot to next
              division's same string (suri) or next string (oshibachi)
  Triplet bracket drawn as right-angled SVG path below staff
    (y 20–22mm, "3" centred at 22mm)
  Dynamic hairpins (crescendo <, decrescendo >): two straight lines from a tip
    y positions (mm from top of notation layer): tip 23.09, lines 22.32 and 23.87
    (HAIRPIN = { centreY: 3.091, opening: 1.548, inset: 0.8 }, relative to the below zone top)
    opening 1.55mm; inset 0.8mm from the span's outer division edges
    stroke black, width 1 (0.265mm; same as arcs and triplet brackets)
    lower edge stays inside the zone; upper edge clears マ by 0.2mm
    and the triplet bracket line (22.0mm) by 0.05mm
    the triplet "3" (computed 11pt) overlaps the hairpin by up to 0.9mm (accepted)
  Text boxes are not part of the arc layer SVG: they are HTML elements appended
    to .notation-layer by renderTextBoxes (called from renderArcLayer). See TEXT BOX.

======================================================
SURI / OSHIBACHI WORKFLOW
======================================================
Arc can be created in any of three flows:

Flow A: activate first
  1. Select a division (no tsubo required)
  2. Click suri/oshibachi — arc armed, placeholder drawn
  3. Enter start tsubo — arc anchors to that slot
  4. Enter end tsubo on a later division — arc resolves

Flow B: enter start tsubo first
  1. Enter start tsubo
  2. Click suri/oshibachi — arc armed with string known
  3. Enter end tsubo on a later division — arc resolves

Flow C: enter both tsubo first (original flow)
  1. Enter start tsubo
  2. Enter end tsubo on a later division
  3. Navigate back to start division
  4. Click suri/oshibachi — arc resolves immediately

Clearing (Backspace, Delete and the Clear button behave identically, see CLEARING):
  Slot clear of the start tsubo reverts a resolved arc to armed (placeholder)
  Slot clear of the last tsubo of an armed division removes the arc entirely
  Division clear and range clear remove resolved and armed arcs on the division
  Whole-unit clear (several staff units selected, Clear Page) removes all arcs,
    including armed ones
  Slot clear of the target tsubo of a resolved arc leaves the arc in place
  Pressing suri/oshibachi again on the division also removes the arc

======================================================
BARLINES
======================================================
Every staff-unit is free placement. There is no per-unit template mode.
Each barline: { "position": <0-32>, "type": "normal" | "open-repeat" | "close-repeat" | "double-repeat" | "stop", "repeat": "<digits>" }
  "repeat" only on close-repeat (positions 1-32) and double-repeat (positions 1-31); omitted when empty.
  double-repeat only at positions 1-31.
Positions 0 and 32 always exist and are never removed.
Barline colour: #d3d3d3
Barlines are not directly clickable. They are edited through the
selected time-division (see Editing).

Template buttons (shortcuts): 0, 2, 4, 8
  0: []   2: [16]   4: [8, 16, 24]   8: [4, 8, 12, 16, 20, 24, 28]
  Replace all interior barlines (1-31) with normal barlines at these positions.
  Positions 0 and 32 keep their current types.
  "0" removes all interior barlines.

Editing (division k selected, 1-based; data-time-index k-1),
barline button of type X pressed. Acts on the right edge, position k:
  k = 2..32:
    no barline -> place X
    different type -> change to X
    same type -> remove (position 32: no change)
  k = 1, cycle (the mark moves, never two at once):
    position 1 is X -> remove position 1, set position 0 to normal
    else position 0 is X -> set position 0 to normal, place/change X at position 1
    else -> set position 0 to X
    (a double-repeat at position 1 is replaced as "different type -> change")
  X = double-repeat (exception, no cycle):
    k = 1..31: plain toggle at position k (no barline -> place,
      different type -> change, same type -> remove); position 0 never touched
    k = 32: no effect
  Barline button presses are ignored while a multi-division range is selected
  (no visual change to the buttons).
  Barlines kept sorted by position.
  Undo/redo: one step per press.
  No keyboard shortcuts for barlines.

Drawing (drawBarlines), x = position line, offsets in mm:
  thin 0.3, thick 0.6, dot radius 0.3 at y 8 and 12
  thickOff = dotOff = 1.05 (centre-to-centre)
  open-repeat:   thick -1.05, thin 0, dots +1.05
  close-repeat:  dots -1.05, thin 0, thick +1.05
  double-repeat: dots -2.10, thin -1.05, thick 0 (shared), thin +1.05, dots +2.10
                 centred on the position, half in each neighbouring division
  stop:          thin 0, thick +1.05

Whole-unit clears (Backspace, Delete or Clear with several staff units selected,
Clear Page, before whole-unit paste) leave barlines unchanged. Division and range
clears never touch barlines. A single clicked staff unit is not clearable.

Copy/paste:
  Whole-unit: barlines pasted as-is.
  Range: interior positions startIndex + 1 to endIndex are copied.
    Target interior barlines in the paste range are removed, then pasted
    ones applied at the offset (even if none were copied).
    Positions 0 and 32 are never changed; pasted barlines at or beyond 32
    are dropped. Paste and barlines form one undo step.
Paste of any kind is its own undo step.

Repeat number (close-repeat at positions 1-32, double-repeat at positions 1-31):
  Editable box in the above zone, right-aligned to the barline's position line
  (for double-repeat it sits above the left half).
  Font 6pt, colour #8a8a8a. May overlap the finger mark of the division to its left.
  User types digits only (max 2); the "×" is added by CSS.
  Empty: faint "×?" placeholder on screen, hidden in print. Filled: printed.
  Stored as "repeat": "3" on the barline object, omitted when empty.
  Dropped if the barline type changes or the barline is removed
  (including by template buttons 0, 2, 4, 8).
  Edit is one undo step, recorded on blur if the value changed. Enter finishes editing.
  Typing in the box does not trigger shortcuts.
  Carried by range and whole-unit copy/paste.

======================================================
GREAT STAFF
======================================================
Connects two or more adjacent staff-units with a continuous
extended barline at position 0 and position 32, indicating
simultaneous music played by separate shamisen.

Roles (data-great-staff):
  "start"   first unit in group — barline extends downward to 25mm
  "middle"  intermediate units — barline extends both directions (0–25mm)
  "end"     last unit in group — barline extends upward to 0mm

Toggle button (palette section "Misc" / "その他"):
  Selection includes a grouped unit -> removes the group(s)
  Otherwise, 2+ units selected -> creates a group
  Otherwise -> no effect
  No pressed, active or disabled styling.
  One undo step per press.
Persistent: saved to data model as greatStaff field on staff-unit

======================================================
DYNAMICS (HAIRPINS)
======================================================
Palette buttons in the Misc / その他 section: < (Crescendo / クレッシェンド),
> (Decrescendo / デクレッシェンド). Commit function: commitDynamic.
Span:
  Multi-division range -> first to last selected division
  Single division -> that division and the next (division 32 -> 31-32)
  Nothing selected or multi-staff selection -> no effect
Same button on the same span removes; the other button converts.
A new hairpin replaces any hairpin it overlaps in the same staff-unit.
One undo step per press. No keyboard shortcut. Within one staff-unit only.
Clearing the start division (division clear, range clear, whole-unit clear)
removes the hairpin; clearing other divisions in the span does not. A slot clear
never removes it.
Copy/paste:
  Range: hairpins starting in the range are carried, clipped to the range end;
    on paste, clipped to index 31; dropped if shorter than 2. A pasted hairpin
    replaces an existing one it overlaps.
  Whole-unit: carried unchanged.
Hidden units and print: as other marks.

======================================================
TEXT BOX
======================================================
Free text for performance notes, in the below zone only.
Palette button in the Misc / その他 section: "Text" / "テキスト"
(data-action="text-box"). No keyboard shortcut. Commit function: commitTextBox.
Span: same rules as hairpins
  Multi-division range -> first to last selected division
  Single division -> that division and the next, capped so the box ends at
    division 32 (division 32 -> 31-32)
  Nothing selected or multi-staff selection -> no effect
Same span pressed again removes the box (text included). A new box replaces any
box it overlaps in the same staff-unit. Several boxes per unit. One undo step per
press. May overlap マ, triplet brackets and hairpins.
Layout:
  .text-box-clip   absolute, left at the start division, extends to position 32,
                   overflow hidden, pointer-events none, z-index 3, height 4mm,
                   top aligned to the below zone
  .text-box        contentEditable, width = box span (sets the click area),
                   IBM Plex Sans JP 8pt, black, one line, text overflows to the right
  Text beyond position 32 is clipped; the box turns red on screen only while
  clipped (black in print).
  Empty box: faint "Text" / "テキスト" placeholder on screen only; prints nothing.
Editing:
  Click focuses the text and does not change the selection or start a drag.
  Typing, Backspace and Delete in the box never trigger shortcuts or clear.
  Plain text only (paste is flattened to one line). Enter finishes editing.
  Edit is one undo step, recorded on blur if the text changed.
  renderTextBoxes skips rebuilding a unit while one of its boxes has focus.
Clearing: clearing the start division (division, range or whole-unit clear)
  removes the box; clearing other divisions in the span leaves it; a slot clear
  never removes it.
Copy/paste: as hairpins. Range: boxes starting in the range are carried, clipped to
  the range end; on paste clipped to index 31; dropped if shorter than 2; a pasted
  box replaces an existing one it overlaps. A one-division copy carries no box.
  Whole-unit: carried unchanged.
Hidden units hide their text boxes.
Saved: textBox (omitted when empty) + textBoxLength on the start division.

======================================================
TRIPLETS
======================================================
Use 3 consecutive time-divisions, all active (triplet notes 1-3)
Bracket drawn below staff on .arc-layer, spanning all 3 divisions
Keyboard shortcut: t
Toggle off: t on any triplet division, or Backspace / Delete / Clear with a
triplet division or one of its slots selected. Either removes the triplet marking
from all 3 divisions only; their content is kept (a second Clear then clears the
selected slot or division). A drag-selected range clear does not remove triplet
markers (content is cleared). A multi-unit clear and Clear Page remove them.

======================================================
CLEARING
======================================================
handleClear() is the single clear path. Backspace, Delete and the palette Clear
button all call it and behave identically in every selection state. Ignored while
typing in a contentEditable field (header, lyrics, bar number, repeat box, text box).
By selection state:
  Several staff units selected  whole-unit clear of each (clearStaffUnitContent)
  Division range (drag/shift)   commitClearDivision on each division in the range only
  Triplet division, or a slot   removes the triplet (see TRIPLETS); nothing else
    in it, selected
  Slot selected                 commitClearSlot (that slot only)
  Division selected, no slot    commitClearDivision
  Single staff unit selected,   nothing (intentionally not clearable)
    no division
Slot clear: empties the slot. If it was the start tsubo of a resolved arc the arc
  reverts to armed. If no tsubo remain: duration cleared and any armed arc removed.
  Does not touch ha, maebachi, finger, sukui/hajiki/keshi/uchi, hairpin or text box.
Division clear (also used per division by a range clear): slots, rest, duration,
  finger, ha, maebachi, sukui, hajiki, keshi, uchi (flags and glyphs), below-zone
  content, resolved and armed arcs, and a hairpin / text box starting on it.
  Triplet markers and barlines are kept.
Whole-unit clear (clearDivisionFully on all 32 divisions; also used by Clear Page
  and on target divisions before a paste): everything a division clear removes,
  plus triplet markers and armed (placeholder) arcs. Keeps barlines, great staff,
  hide state, bar number and part label. Clear Page also empties the page's lyric lines.
Undo: every clear that changes the document is one undo step; a clear that changes
  nothing records none. handleClear and the Clear Page and duration "-" actions end
  with pushHistoryIfChanged(), which pushes only if the serialised document differs
  from the current history entry. Applies to slot, division, range, multi-unit and
  Clear Page clears.

======================================================
PALETTE AND KEY RULES
======================================================
Pressing the value already set removes it (toggle off):
  Rest (palette ● and r key)         removes the rest; otherwise sets it
  Duration single / double (palette) removes the underline only; the dot stays
  Finger Ⅰ / Ⅱ / Ⅲ (palette)         removes the finger mark
The cycle keys read the stored value of the selected division:
  d   none -> single -> double -> none   (data-duration-underline; dot is kept)
  f   none -> Ⅰ -> Ⅱ -> Ⅲ -> none        (data-finger)
The duration "-" and finger "-" buttons clear (duration "-" clears underline and dot).
Duration "-" is one undo step only if something changed.
Setting, changing or removing the underline never clears the duration dot; the
dotted class is re-applied to the bottom-most tsubo slot (the underline anchor).
A rest clears duration including the dot.
Delete Page (valid page only) and Hide / Show (a unit's blank state changed) are
one undo step each; cancelled or invalid input and Hide with nothing selected
record nothing.

======================================================
BLANK UNITS
======================================================
Staff units only can be hidden, using the Hide palette button (Editing row).
Lyric units cannot be hidden. Older files may carry a blank flag on a lyric unit;
it is ignored on load and not saved.
Toggled with the Hide/Show button in the Editing palette row.
Hidden staff units:
  - Occupy their normal space in the layout
  - Are fully selectable (click or drag)
  - Show amber selection outline when selected
  - Are not visible in print
  - Hide their text boxes with the rest of the staff section
Persistent: saved as blank: true on the staff unit object.

======================================================
JS ARCHITECTURE
======================================================
Input Layer    palette clicks, keyboard
Intent Layer   { action, value }
Dispatch Layer dispatchCommit(intent)
Commit Layer   commitTsubo, commitRest, commitDurationUnderline,
               commitDurationDot, commitSukui, commitHajiki,
               commitKeshi, commitUchi, commitMaebachi, commitHa,
               commitTechArc, commitTriplet, commitFinger,
               commitClearSlot, commitClearDivision,
               commitClearRest, commitClearDuration,
               commitBarlineType, commitGreatStaffToggle,
               commitToggleBlank, commitDynamic, commitTextBox

Clear path (outside the dispatch layer):
  keydown (Backspace / Delete) and the palette Clear button both call
  handleClear() directly. keyToIntent still maps the keys to { action: "clear" }
  for the keydown handler, but dispatchCommit has no "clear" case.
  handleClear picks the commit function from the selection state (see CLEARING):
  clearMultiSelectionContent (range or several units), commitTriplet,
  commitClearSlot or commitClearDivision, then calls pushHistoryIfChanged().
History:
  pushHistory()           unconditional snapshot (dispatch actions, paste, barlines)
  pushHistoryIfChanged()  snapshot only if the serialised document differs from the
                          current history entry. Used by handleClear, Clear Page,
                          the duration "-" button and text box blur.
  commitTextBox(): returns true if the unit changed; dispatchCommit then calls
                   pushHistory() (as commitDynamic). Text edits are recorded on
                   blur by the box itself (renderTextBoxes).
Palette-only actions handled in handlePaletteInput before dispatch: clear,
  duration-empty, editing (copy / paste), toggle-blank. The same-value toggle-off
  for duration underline and finger is also applied there.

Selection model:
  selectedSlot        one string-slot at a time
  selectedDivision    one time-division at a time
  selectedStaffUnit   one staff-unit at a time
  multiDivisionSelection  { staffUnit, startIndex, endIndex }
  multiStaffSelection     { startUnit, endUnit }
  slot selection implies division selection
  division may be selected without slot
